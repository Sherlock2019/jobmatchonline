Sidebar top slot is Profile, not a role toggle; hide role-view chip for real accounts

- The sidebar's top "Workspace" switcher opened whichever demo persona
  matched the other role, discarding the real session for any real
  account that clicked it. Repurposed it into the Profile entry point
  (photo, name, role, arrow -> profile page) and removed the now-
  redundant "View my profile" button that sat at the bottom of the
  sidebar, so there's a single profile link instead of two.
- The topbar "Candidate view / Recruiter view" chip called the same
  changeRole() helper, which always logs in as `${role}-demo` — for a
  real account this silently swapped them into the demo persona. Now
  only rendered when the signed-in viewer is a demo account.
